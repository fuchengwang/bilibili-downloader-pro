# BBDown Pro 更新模块

应用的更新请求与激活请求使用同一服务地址及 AppID `bbdown-pro`，两者独立运行。激活接口、设备标识和已有授权保存位置保持原样。更新器不会修改下载目录、视频、账号信息或授权文件。

设置页只显示“自动检查更新”勾选项，默认开启。应用窗口加载完成后，距离上次检查尝试至少七天才检查一次；关闭后不做自动检查，手动“检查更新”仍可使用。运行中不设周期定时器。失败也记录本次尝试时间，避免每次启动反复请求；429 的冷却时间保存到本地。自动发现更新只显示设置图标蓝点，下载须由用户点击。

## 模块分工

- `pkg/update`：从服务端仓库复制的纯标准库 SDK，负责检查版本、HTTP 下载、镜像切换、断点续传、完整大小和 SHA-256 校验及发布状态确认。协议保持与服务端一致，SDK 不执行安装。
- `pkg/updater`：客户端的一个状态管理器，加 Windows/macOS 各自的安装适配。更新策略、上次检查、推荐版本和安装计划保存在已有配置目录的 `updates/` 子目录。
- `app_update.go`：转发设置页操作，在重启前保存并暂停下载任务，等待下载文件关闭；遇到正在合并的任务时暂不重启。
- `UpdatePanel.vue`：呈现更新状态与按钮，自动检查不发弹窗或 toast。状态事件带递增顺序号，避免较晚送达的旧进度覆盖完成状态。

断点缓存按发布版本和文件 SHA-256 隔离，单个地址保留自己的部分文件。下载中断可继续；完整包可复用。完整下载后重新确认它仍是服务端推荐版本，再准备安装。准备失败不修改已安装应用，可重试。安装临时文件和旧版备份与当前应用同目录，避免跨卷替换。

“暂不重启”或关闭完成提示只隐藏提示，已准备的更新保留。下次启动先取得应用单实例锁，再启动辅助更新进程并退出；立即重启也走同一辅助进程。辅助进程由当前可运行的程序复制得到，先等待当前进程真正退出，再使用原生文件操作替换程序。安装失败关闭自动再次安装，显示重试入口，避免每次打开都失败循环。软件被移动或暂存文件丢失时可以重新下载准备。

## 发布包要求

1. 只修改 `wails.json` 中的 `info.productVersion`，采用正式 `X.Y.Z`。运行程序、授权客户端版本、更新查询和 Wails 包元数据均从此处读取；服务端发布版本须一致。
2. Windows 使用现有 ZIP 格式，根目录只有主程序 `BBDown Pro.exe`。更新器只提取这个文件，检查 PE 架构和程序自报版本。其他压缩包路径不会被提取。退出后调用 Windows `ReplaceFileW`，保存旧版备份；临时文件占用时有限等待，失败保留旧版。
3. macOS 使用现有签名、公证、装订的 DMG，根目录包含 `BBDown Pro.app`。更新器检查完整 bundle 签名、Bundle ID、当前开发者 Team ID、版本及本机架构，检查程序自报版本。通过 `RENAME_SWAP` 一次交换完整应用包，旧版留在暂存路径供恢复。
4. 原样发布经过现有 Release 流水线验证的包到下载地址，在更新后台试下载成功后发布。不要用后台版本号覆盖包内实际版本。首个带更新模块的版本需要正常安装，之后才可应用内更新。

当前软件所在目录必须可写。比如 macOS 应先把 DMG 内应用安装到本机再运行，Windows 不应把程序放在无法写入的位置；遇到权限不足会保留当前程序并提示，更新器不安装后台服务或自动提权。

新程序窗口完成加载后才清理旧版备份。安装中断后，下一次启动会以程序版本和已安装文件哈希核对状态。用户数据不参与替换。完整安装后若发现业务回归，可在服务端发布更高版本修复；后台撤回只阻止尚未完成准备的更新，不会卸载已经安装的版本。

## 验证

```sh
pnpm --dir frontend exec node --test tests/quality-loading.test.mjs tests/clipboard.test.mjs tests/update-panel.test.mjs
pnpm --dir frontend run build
go test -race -short ./...
BBDOWN_NATIVE_UPDATE_TESTS=1 go test -race -count=1 ./pkg/update ./pkg/updater
```

最后一项在隔离临时目录中创建本机安装包，实际下载、校验、准备、延后到下次启动、辅助进程替换与打开新版，检查旧版恢复及文件锁；macOS 使用真实 DMG 和无界面测试 app，Windows 使用真实 EXE/ZIP。它不会修改安装中的 BBDown 或真实用户配置。CI 的 `Test Native Updater` 在 Windows/macOS 分别执行该项；全量后端测试同时覆盖重启拒绝中断合并、保存暂停任务及等待下载文件关闭。
